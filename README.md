## このリポジトリの現状

このリポジトリは現在、最小構成です。

- `README.md`: プロジェクト名と基本説明（このファイル）
- `LICENSE`: ライセンス情報

現時点では `src/` や `tests/` などの実装ディレクトリはまだありません。

## 新規参加者がまず知っておくべきこと

1. **まだ初期化段階のコードベース**
   - 実装コードはこれから追加される想定です。
2. **ドキュメント駆動で土台を作るフェーズ**
   - 先に構成・規約・開発フローを決めると、後の開発が速くなります。
3. **ライセンス確認**
   - 依存導入・コード追加時は `LICENSE` と整合する運用にしてください。

## 次に学習・整備するとよい事項（推奨順）

1. **技術スタックの決定**
   - 言語、フレームワーク、パッケージ管理、実行環境を決める。
2. **標準ディレクトリ構成の策定**
   - 例: `src/`, `tests/`, `docs/`, `scripts/`, `.github/workflows/`。
3. **開発ルールの明文化**
   - フォーマッタ、Linter、コミット規約、PR テンプレート。
4. **最小機能の雛形実装**
   - エントリーポイント + 単体テスト 1 本 + CI。
5. **オンボーディング文書の充実**
   - セットアップ手順、よくある問題、設計方針。

## 参加直後のおすすめアクション
